# Laufapp v0.2.16

## Aktivitätszuordnung

Automatisches Matching erfolgt nur, wenn ein realer Lauf am selben Tag mindestens 90 % der geplanten Distanz erreicht. Eine längere reale Distanz ist zulässig und gilt als Übererfüllung. Unterhalb der 90-%-Grenze bleibt die Planaktivität offen.

Im Menü eines unverknüpften Laufs steht nun **„Aktivität verknüpfen“** zur Verfügung. Dort kann eine unverknüpfte Planaktivität desselben Tages bewusst manuell gewählt werden; die Distanzgrenze gilt für diese explizite Nutzerentscheidung nicht.

Ein realer Lauf kann nicht gleichzeitig mit mehreren Planaktivitäten verknüpft werden.

Keine Datenbankschemamigration.
